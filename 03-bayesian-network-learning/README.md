# Bayesian Network Learning

Implementation and evaluation of parameter learning and structure learning methods for Bayesian Networks using Python.

## Overview

This section focuses on learning Bayesian Network models from data.

The notebooks investigate how model parameters and network structures can be learned from observed data, as well as how model complexity affects training performance and generalization.

## Methods

The following methods and concepts are implemented and evaluated:

- Maximum Likelihood Estimation (MLE)
- Parameter Learning
- Bayesian Network Structure Learning
- BIC (Bayesian Information Criterion)
- Model Dimension
- Laplace Smoothing
- Structure Search
- Maximum Number of Parents
- Variable Ordering

## Experiments

The experiments investigate:

- Training and test log-likelihood
- Effect of dataset size on parameter estimation
- Model complexity and generalization
- Overfitting
- Laplace smoothing
- Bayesian Network structure search
- Influence of the maximum number of parents
- Comparison of different variable orderings
- Evaluation using datasets of different sizes

## Notebooks

### 1. Parameter Learning

Implementation of parameter learning using Maximum Likelihood Estimation.

The experiments analyze training and test log-likelihood, the effect of dataset size, model complexity, and Laplace smoothing.

### 2. Structure Learning

Implementation and evaluation of Bayesian Network structure learning using BIC-based model selection.

The experiments investigate structure search, model dimension, maximum parent constraints, variable ordering, and generalization across datasets of different sizes.
