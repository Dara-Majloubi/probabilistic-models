# Probabilistic Models

Implementation of probabilistic inference, learning, and sequential modeling methods using Python and NumPy.

This repository contains selected coursework projects from the Master's program in Artificial Intelligence at Johannes Kepler University Linz (JKU).

## Topics Covered

- Bayesian Networks
- Exact Inference
- Approximate Inference
- Bayesian Network Learning
- Hidden Markov Models
- Probabilistic Sampling
- Model Learning and Selection
- Maximum Likelihood Estimation
- Expectation-Maximization

The projects in this repository demonstrate practical implementation and evaluation of probabilistic modeling techniques, with a focus on inference, learning, model selection, and sequential probabilistic models.
