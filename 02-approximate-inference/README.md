# Approximate Inference

Implementation and evaluation of approximate inference methods for Bayesian Networks using Python.

## Overview

This section focuses on sampling-based inference methods for Bayesian Networks.

The implementations explore how probabilistic queries can be approximated by generating and analyzing samples from the underlying graphical model.

## Methods

The following methods are implemented and evaluated:

- Topological Sorting
- Forward Sampling
- Rejection Sampling
- Likelihood Weighting
- Gibbs Sampling

## Experiments

The notebooks investigate:

- Generation of samples from Bayesian Networks
- Approximation of probabilistic queries
- Effect of sample size on inference accuracy
- Comparison of sampling-based inference methods
- Resampling distributions
- Computational aspects of approximate inference

## Notebooks

### 1. Topological Sampling

Implementation of topological sorting and forward sampling, followed by rejection sampling for approximate inference.

### 2. Likelihood Weighting

Implementation of likelihood weighting and analysis of sampling behavior and edge counts.

### 3. Gibbs Sampling

Implementation of Gibbs sampling and analysis of the resulting resampling distribution.
